# Ejuvweriemu Nelson Student Portfolio

A responsive academic portfolio and student planner for Ejuvweriemu Nelson, a Software Engineering student at MIVA Open University.

## Website pages

- `index.html` — welcome page, student portrait, and short biography
- `about.html` — personal background, education timeline, career aspiration, skills, hobbies, and Nelson’s audio recording
- `projects.html` — eggplant yield research, coconut oil antimicrobial research, and the RiNess peanut burger flyer
- `planner.html` — task creation, completion, deletion, filters, and browser storage
- `contact.html` — required name, email, phone, and message fields with JavaScript validation

## Technology requirements included

Semantic HTML, a shared external stylesheet, responsive CSS Grid and Flexbox layouts, navigation links, a data table, lists, images, an audio element, CSS transitions, JavaScript event handling and DOM updates, required-field checks, email validation, digits-only phone validation, and an interactive task array saved in browser local storage.

## Run locally

Open `index.html` in a web browser. The pages use relative paths and require no build step.

## Publish with GitHub Pages

1. Create a GitHub repository and upload the contents of this folder, keeping `index.html` at the repository root.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, and save.
4. Copy the live website URL shown on the Pages settings screen after deployment completes.

The contact form validates in the browser but needs a form service or backend to deliver messages. Planner tasks are stored only in the visitor's current browser and device. The eggplant photo and coconut-oil lab photos illustrate the research entries; add original field or report images if you want to document the work further.
